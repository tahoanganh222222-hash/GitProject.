# Mộc Books — giới thiệu sách

Landing Page tĩnh responsive giới thiệu cuốn sách giả tưởng "Dưới tán cây kể chuyện". Dự án dùng HTML, Bootstrap 5.3.8 và CSS tùy chỉnh; hình bìa sách là SVG lưu cục bộ.

## Các phần trong trang

Header/navigation, Book Overview, Author, Features, Prices, Download, Reader's Say và Footer.

## Chạy trang

Mở index.html bằng trình duyệt. Navbar co lại trên màn hình nhỏ; Bootstrap CSS/JS được tải từ CDN, nên cần kết nối Internet để dùng đầy đủ Bootstrap.

## Tài liệu tham khảo

- Mẫu Bootstrap của CodeGym: https://github.com/hoanv7169/bootstrap-demo
- Bootstrap 5.3: https://getbootstrap.com/docs/5.3/getting-started/introduction/
