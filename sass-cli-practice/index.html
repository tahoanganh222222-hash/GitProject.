SCSS thành CSS
chỉ trong một lệnh.

Dùng Sass CLI để biên dịch kiểu giao diện, rồi bật chế độ theo dõi để CSS được cập nhật khi SCSS thay đổi.

Xem ví dụ →
main.scss
$accent: #86efac;

.hero {
  padding: 4rem 0;
  h1 {
    color: $accent;
  }
}
✓ compiled successfully

Các bước thực hành

Một lệnh, nhiều khả năng.

01

Biên dịch một file

sass scss/main.scss css/main.css

Chuyển tệp SCSS thành CSS sẵn sàng dùng trên trang web.

02

Theo dõi thay đổi

sass scss/main.scss css/main.css --watch

Sass tự biên dịch lại stylesheet khi mã nguồn được lưu.

03

Biên dịch cả thư mục

sass scss/:css/ --watch

Biên dịch các stylesheet SCSS trong thư mục sang CSS.
